# 🚀 BotPortfolio

> Telegram-бот для создания и управления личным портфолио проектов прямо внутри Telegram.

BotPortfolio позволяет хранить свои проекты, редактировать информацию о них, указывать технологии и ссылки, отслеживать статус разработки и быстро получать аккуратно оформленную информацию о каждом проекте.

---

## ✨ Возможности

* 📁 **Создание проектов**
* ✏️ **Редактирование информации**
* 📝 Название и описание проекта
* 🔗 Ссылка на проект
* 📊 Статус проекта
* 🛠️ Используемые технологии и навыки
* 👀 Просмотр подробной информации о проекте
* 🗂️ Управление списком проектов
* ❌ Возможность отменить текущее действие
* 🎨 Удобный интерфейс с Telegram-кнопками и эмодзи
* 💾 Хранение данных через базу данных

---

## 🖥️ Как это выглядит

Бот работает непосредственно в Telegram и использует:

**Reply Keyboard**
для основных действий пользователя.

**Inline Keyboard**
для выбора конкретного проекта и управления его параметрами.

Информация о проекте отображается в виде структурированной карточки:

```text
╔════════════════════════════════🌟
║ ПРОЕКТ: My Project
╠════════════════════════════════
║ 📝 Описание:
║ Мой проект на Python
║
║ 🔗 Ссылка:
║ https://example.com
║
║ 📊 Статус:
║ 🟢 В разработке
║
║ 🛠️ Навыки:
║ Python, Telegram API
╚════════════════════════════════
```

## 🧩 Архитектура

Проект разделён на несколько основных файлов:

```text
botportfolio/
│
├── bot.py       # Telegram-бот и обработчики
├── logic.py     # Работа с базой данных и логика проекта
├── draft.py     # Черновая / дополнительная логика
└── README.md    # Документация
```

### `bot.py`

Основная часть Telegram-бота.

Отвечает за:

* обработку сообщений;
* команды;
* Telegram-кнопки;
* создание и редактирование проектов;
* отображение информации;
* взаимодействие пользователя с ботом.

### `logic.py`

Слой работы с данными.

Здесь находится логика управления проектами и взаимодействия с базой данных.

### `draft.py`

Дополнительный файл для разработки и тестирования отдельных идей проекта.

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/Blablaber15/botportfolio.git
cd botportfolio
```

### 2. Создание виртуального окружения

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

**Linux / macOS:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install pyTelegramBotAPI
```

Если в проекте используется файл `requirements.txt`, достаточно выполнить:

```bash
pip install -r requirements.txt
```

---

## 🔑 Настройка

Перед запуском необходимо указать токен Telegram-бота.

В проекте используется конфигурация:

```python
TOKEN = "YOUR_BOT_TOKEN"
```

> ⚠️ Никогда не публикуйте настоящий Telegram Bot Token в GitHub.

Для публичного репозитория рекомендуется хранить секретные данные в переменных окружения или отдельном конфигурационном файле, который добавлен в `.gitignore`.

---

## ▶️ Запуск

После установки зависимостей запустите:

```bash
python bot.py
```

После запуска откройте своего бота в Telegram и используйте доступные команды.

## 🎯 Для чего создан проект

BotPortfolio задуман как простой инструмент для разработчика, который позволяет вести собственное портфолио без отдельного сайта или сложной панели управления.

Все основные действия выполняются прямо в Telegram.
